# Ноутбуки Jupyter (DataLabs)

Плагин DataLabs — Jupyter в Пульсе. Владелец открывает `.ipynb` в «Файлах» (там же «Создать ▾ → Ноутбук»), весь
JupyterLab — пункт меню «DataLabs». Тебе — ядро Python с pandas, numpy, polars, duckdb, scipy, scikit-learn,
statsmodels, matplotlib, seaborn, plotly, openpyxl. Код ядра видит все «Файлы» владельца: рабочая папка ядра —
папка ноутбука (или `--cwd`), корень «Файлов» — `os.environ["PULSE_FILES"]`.

Бери плагин, когда нужно посчитать, а не прочитать: таблица на тысячи строк, сводная, график, статистика, прогноз,
регулярный отчёт. Пару чисел из маленького CSV посчитаешь и без ядра.

## Посчитать и показать владельцу

```bash
pulse datalabs exec --cwd "Продажи" --code 'import pandas as pd, matplotlib.pyplot as plt
df = pd.read_csv("2026-10.csv"); df.info(); df.head()'
pulse datalabs exec --code 'df.groupby("регион")["выручка"].sum().sort_values().plot.barh(); plt.title("Выручка")'
pulse datalabs save --path "Продажи/Разбор за октябрь.ipynb" --title "Продажи за октябрь"
```

- `exec` — ячейка в **живом ядре**: переменные живут между вызовами (`--session` — отдельное ядро на задачу,
  по умолчанию `main`; `--cwd` — рабочая папка при запуске ядра). Длинный код — `--code_file путь.py`.
- Ответ: `status` (`ok` | `error` | `timeout`), `output` — текст, таблицы (`text/plain`), трейсбэк; картинки
  сохраняются файлами — `[картинка: Plugins/…/ячейка 3-1.png]`: их можно показать владельцу ссылкой или
  приложить к ответу. Импорты — сам, в первой ячейке.
- Выводи мало: `head()`, `describe()`, `value_counts().head(20)`; ответ обрезается на 20 000 символах.
- Ячейка дольше 5 минут (`--timeout` до 840 с) прерывается. Долгие расчёты — в ноутбук и `run`.
- `save` собирает ноутбук из выполненных ячеек ядра (ошибочные выбрасываются, `--errors true` — оставить) —
  это и есть результат для владельца: код, таблицы, графики, можно перезапустить. Дай ссылку:
  `[Разбор за октябрь](/files?path=Продажи/Разбор%20за%20октябрь.ipynb)`.
- `sessions` — твои ядра; `reset --session S` — с чистого листа; `close --session S` — когда задача закончена.
  Ядро без дела останавливается само через час (настройка владельца) — тогда `exec` скажет, что переменных нет.

## Готовый ноутбук

```bash
pulse datalabs read --path "Отчёты/Еженедельный.ipynb"                  # ячейки текстом с выводом
pulse datalabs read --path … --cells 3-6 --outputs false
pulse datalabs run --path "Отчёты/Еженедельный.ipynb" --params '{"week": "2026-W42"}'
pulse datalabs export --path "Отчёты/Еженедельный.ipynb" --to pdf --no_input true
```

- `run` выполняет ноутбук целиком (papermill) и сохраняет вывод в него же (`--output` — в другой файл).
  `--params` — JSON: значения попадают в ячейку с тегом `parameters` (нет такой — в начало). Ошибка — `ok: false`
  и `error`: номер ячейки, тип, текст, код ячейки. Исправляй ноутбук (`read` → правка файла → `run`), а не
  вывод.
- Ноутбук можно править как обычный JSON-файл (`$PULSE_FS_DIR/…`), но проще собрать новый через `exec` + `save`.
- `export --to html|pdf|py|md` — рядом с ноутбуком (или `--output`); `--no_input true` — без кода.

## Отчёт по расписанию

`report` выполняет **копию** ноутбука (`Отчёты/<имя> 2026-10-21 09-00.ipynb` рядом с ним или в `--to`),
выгружает её в HTML (`--format pdf` — PDF; `--code true` — с кодом) и присылает владельцу ссылку в Telegram и
Пульс. Ноутбук-шаблон не меняется. Не собрался — владелец получает ячейку с ошибкой, команда завершается ошибкой.

```bash
pulse jobs create --name "Отчёт по продажам" --cron "0 9 * * 1" --timeout 3600 \
  --shell 'pulse datalabs report --path "Продажи/Еженедельный.ipynb" --params "{\"weeks\": 1}"'
```

Сначала проверь шаблон руками (`pulse datalabs report --path … --notify false`), потом ставь задание.

## Правила

- Ноутбук — для владельца: заголовок, короткие пояснения Markdown между шагами, понятные подписи осей.
- Не перезаписывай чужие ноутбуки владельца без просьбы: свой результат — новым файлом.
- Пакета нет — `%pip install имя` в ячейке (`exec --code '%pip install …'`); ставится один раз и остаётся.
- Секреты (ключи API, пароли) в код ноутбука не пиши — ноутбук читают и пересылают.
- Память ядер ограничена (2 ГБ на все ядра вместе): большие файлы читай частями, нужные колонки (`usecols`), duckdb/polars
  для CSV и Parquet на гигабайты.
- Не работает — `pulse datalabs check` и расскажи владельцу, что не так.
