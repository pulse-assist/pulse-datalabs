# Плагин «Пульса» — инструкция для Claude Code

Полная инструкция по разработке — [AGENTS.md](AGENTS.md); прочитай её перед работой. Главное:

- Это плагин для «Пульса»: манифест `pulse-plugin.json`, сервер на `pulse_plugin` (`backend/`), Jupyter в том же
  контейнере (`Dockerfile`), команды агентов (`commands.json`), скилл, `INSTALL.md`.
- Тексты для владельца и агентов — по-русски.
- Права — минимально нужные; всё вне `permissions` Пульс отклоняет.
- После изменений: `cd backend && python -m pytest`; `commands.json`, скилл и `INSTALL.md` соответствуют коду.
- Релиз — поднять `version` в манифесте и поставить тег `v<версия>`.
