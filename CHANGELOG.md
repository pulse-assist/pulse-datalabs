# История

## 0.1.1

- Ядра ноутбуков (и прогоны papermill) работают с пониженным приоритетом (nice 10): долгий расчёт больше не
  оставляет сервер плагина без процессора, и Пульс не перезапускает DataLabs посреди прогона из-за молчащего health.

## 0.1.0 — первая версия (10.2026)

- `.ipynb` в «Файлах» — в Jupyter (Notebook 7) прямо в панели просмотра, на телефоне — просмотр; «Создать ▾ →
  Ноутбук»; JupyterLab — пункт меню «DataLabs», русский интерфейс, тема как у Пульса.
- Корень Jupyter — все «Файлы» владельца (контракт 1.11, `files:mount`); контрольные точки — в данных плагина.
- Агенты: живое ядро (`exec`, `sessions`, `save`, `reset`, `close`), ноутбук целиком (`run` — papermill, `read`,
  `export` — html/pdf/py/md), отчёт для планировщика (`report` — копия с параметрами, HTML/PDF, ссылка владельцу).
- Контейнер в своей сети, 2 ГБ / 2 CPU; токен Jupyter — только в прокси плагина, проверка Host и Origin.
